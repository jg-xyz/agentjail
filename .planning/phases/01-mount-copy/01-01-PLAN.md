1. In cli/main.go, extract the ClaudeCode volume assembly logic (lines 497-503) into a new function:

```go
// buildClaudeMountArgs returns the volume args, env args, and dockerSetup
// snippet for mounting ~/.claude into the container with path translation.
// hostClaudePath is the absolute path to ~/.claude on the host.
// hostHome is the host user's home directory (e.g. "/home/jg").
func buildClaudeMountArgs(hostClaudePath, hostHome string) (volumeArgs []string, envArgs []string, setupSnippet string) {
    // Volume: read-only at /tmp/.claude
    claudeTmpMount := fmt.Sprintf("%s:/tmp/.claude:ro", hostClaudePath)
    volumeArgs = []string{"-v", claudeTmpMount}

    // Env: HOST_HOME for sed substitution
    envArgs = []string{"-e", fmt.Sprintf("HOST_HOME=%s", hostHome)}

    // dockerSetup: copy + path translate, skip binaries via grep -qI
    setupSnippet = `if [ -d /tmp/.claude ] && [ ! -d /root/.claude ]; then ` +
        `cp -r /tmp/.claude /root/.claude && ` +
        `find /root/.claude -type f | while IFS= read -r f; do ` +
            `if grep -qI "" "$f" 2>/dev/null; then ` +
                `sed -i "s|${HOST_HOME}/.claude|/root/.claude|g" "$f" 2>/dev/null || true; ` +
            `fi; ` +
        `done; ` +
    `fi; `

    return
}
```

```dockerfile
# Startup script: copies /tmp/.claude (read-only host mount) to /root/.claude
# with host-path substitution so hooks and plugins resolve inside the container.
# Runs from CMD so it executes at container creation for ALL paths including
# non-interactive mode (which bypasses the dockerSetup shell string).
# Idempotent: skips if /root/.claude already exists (e.g. from dockerSetup).
RUN cat > /usr/local/bin/agentjail-init-claude <<'INIT_CLAUDE'
#!/bin/sh
# Copy /tmp/.claude to /root/.claude with host-path substitution.
# HOST_HOME is injected by the agentjail CLI at runtime.
if [ -d /tmp/.claude ] && [ ! -d /root/.claude ]; then
  cp -r /tmp/.claude /root/.claude
  find /root/.claude -type f | while IFS= read -r f; do
    if grep -qI "" "$f" 2>/dev/null; then
      sed -i "s|${HOST_HOME}/.claude|/root/.claude|g" "$f" 2>/dev/null || true
    fi
  done
fi
INIT_CLAUDE
RUN chmod +x /usr/local/bin/agentjail-init-claude
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host -> Container (volume mount) | Host `~/.claude` crosses into container via read-only bind mount |
| Container startup (sed substitution) | HOST_HOME env var is consumed by sed inside the container shell |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | Container writing to host `~/.claude` | mitigate | Mount with `:ro` flag -- container cannot modify host files. Verified by MOUNT-01 test. |
| T-01-02 | Tampering | Malicious HOST_HOME value used in sed | accept | HOST_HOME is set by Go CLI from `user.Current()` (trusted OS call), not from user CLI args. No user-controlled input reaches the sed delimiter. |
| T-01-03 | Information Disclosure | Host credentials in `/root/.claude` copy | accept | `/root/.claude` exists only inside the ephemeral container (`--rm`). Not mounted back to host in Phase 1. Phase 2 will add write-back with ownership handling. |
| T-01-04 | Denial of Service | Large `~/.claude` directory slows startup | accept | `cp -r` + `find|sed` is O(n) on file count. Typical `~/.claude` has <100 files. No mitigation needed for expected sizes. |
| T-01-05 | Elevation of Privilege | Container runs as ubuntu user | accept | Dockerfile sets `USER ubuntu` with passwordless sudo only for `chown`. This is pre-existing and unchanged by this phase. |
</threat_model>
