| Boundary | Description |
|----------|-------------|
| Go CLI → container env | SYNC_MODE value set by CLI, read by container script |
| container /root/.claude → host ~/.claude | Files written back via /tmp/.claude-out:rw bind mount |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | buildClaudeMountArgs /tmp/.claude-out:rw | mitigate | Source /tmp/.claude remains :ro; container cannot corrupt it. Writes go only to /tmp/.claude-out. |
| T-02-02 | Injection | SYNC_MODE env var | accept | Value comes from config file controlled by host user; not user-supplied at container runtime. Only two valid values (additions_only, full); sync script reads it but doesn't execute it. |
| T-02-03 | Privilege Escalation | HOST_UID/HOST_GID env vars | accept | Already injected in Phase 1 from user.Current() (trusted source); this plan reuses the existing pattern without modification. |
